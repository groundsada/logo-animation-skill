# Standalone logo pages

One logo per self-contained HTML. Open any file directly; there is no build
step, server, or external asset.

- `scinet.html`
- `sc26.html`
- `esnet.html` — includes the ten official-vector styles
- `inmon.html`
- `nrp.html` — includes the traced-vector animation
- `caltech.html` — official seal
- `internet2.html` — color wordmark
- `sdsc.html` — dark-blue + gold wordmark
- `index.html` — gallery linking the eight pages

Brand marks remain the property of their owners. The repository's MIT license
applies to the animation code, not to the marks. The generic, reusable skill
lives on the `main` branch; this branch contains the specific logo pages.
